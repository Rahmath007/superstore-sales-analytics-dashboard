# Superstore Sales Analytics Dashboard

## Project Overview

This project is an end-to-end Data Analytics project built using:

- PostgreSQL
- SQL
- Python
- pandas
- matplotlib
- Power BI
- DAX

The goal of the project was to analyse Superstore sales data, identify business trends, and create an interactive dashboard for decision-making.

---

# Tools & Technologies

- PostgreSQL
- pgAdmin 4
- VS Code
- Python
- pandas
- matplotlib
- Power BI
